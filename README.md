# Source Code for Figure Generation

This repository contains the custom R scripts used to generate the figures presented in the manuscript.

## Requirements

The figures were generated using:

- R 4.3.2
- Red Hat Enterprise Linux 8.8

### Main R packages

- tidyverse 2.0.0
- ggplot2 4.0.3
- dplyr 1.2.1
- survival 3.5-7
- survminer 0.5.2
- ggsci 5.0.0
- ComplexHeatmap 2.16.0
- circlize 0.4.18
- ggh4x 0.3.1
- ggpubr 0.6.3
- cowplot 1.2.0
- lemon 0.5.2
- RColorBrewer 1.1-3
- scales 1.4.0

Package versions are listed in:
- `sessionInfo.txt`

## Input

Source data files used for figure generation are available with the manuscript.

## Output

Each script generates the corresponding figure in PDF format.
